`scripts/build-windows.sh` also copies license documents from the exact resolved NuGet runtime and dependency packages into each Windows release. That release's `licenses/RESOLVED-PACKAGES.txt` records the versions used, which can differ from the initial-build snapshot above after SDK updates. The build fails if a shipped package lacks a license document. The ILLink build tool is excluded because it is not part of the distributed receiver.

Development-only tools, including Xcode, .NET SDK, Python, `websockets` and GitHub Actions, are not bundled with Sofa Tap. They retain their respective upstream licenses.
