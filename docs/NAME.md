# Sofatap

**Sofatap by chekusu** combines *sofa* and *tap*: relax on the sofa and tap your phone to control the computer. The name was selected on **2026-10-11**; the user subsequently specified that it is one complete word, with no space between sofa and tap.

The public brand is **Sofatap**. Use only the initial S as a capital in ordinary copy. Existing technical targets and executable names retain **SofaTap** for compatibility; the repository remains **`chekusu/sofatap`**. See [brand guidance](BRAND.md) for UI, promotional images, video copy and language conventions.

## Chinese-market name proposal

**沙发瘫** — using 瘫, as in 瘫倒 — is the recommended Chinese name. It communicates the relaxed living-room setting, is short enough to remember, and echoes the sound of Sofatap. A clear presentation is **沙发瘫 · Sofatap**, with the line **躺在沙发，电脑在手。** The current app display name stays Sofatap while this Chinese name remains a proposal.
