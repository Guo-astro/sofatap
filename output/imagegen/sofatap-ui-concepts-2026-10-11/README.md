# Sofatap 跨平台 UI 概念方案

五组通过 Image Generation 制作的视觉提案，每组同时展示 **Windows、macOS 和 Linux** 接收器，以便比较三端统一后的样子。图片是设计概念，**不是现有产品截图**；其中的二维码与设备信息仅为演示占位，不用于真实配对。

打开 [离线方案画廊](index.html) 可查看全部大图，点击任意图片可查看原图。画廊不依赖外部字体、脚本或网络服务；下载本目录后可直接在浏览器中打开。这个 HTML 只用于审阅概念图，产品接收器的配对界面仍须使用原生 UI。

## 共同要求

- 品牌始终写作 **Sofatap**，一个完整的词，只有首字母 S 大写。
- 三端使用原生窗口展示配对二维码；手机扫码连接，配对流程不打开浏览器。
- 品牌、信息层级与主要操作保持一致，同时保留各系统的原生窗口操作习惯。
- 配对状态、连接状态与权限说明在正式实现中须准确反映实际功能；生成图片不能代替可访问性检查或实机验证。
- 图内二维码、设备名称等均是演示占位，不包含真实配对凭据。

## 选择之后

当前尚未选定或实施任何方案。可以选择一个编号，也可以组合不同方案的配色与布局。确认方向后，再统一产品中的字体、间距、图标、按钮、配对及连接状态。该目录的产物只用于设计审阅，不会自行改变现有产品 UI。

生成提示词见 [prompts.json](prompts.json)，生成与文件记录见 [manifest.json](manifest.json)。
