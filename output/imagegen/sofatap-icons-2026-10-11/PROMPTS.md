Created 2026-10-11 with the built-in image_gen tool. Five separate generation calls; no existing AppIcon will be overwritten.

Product direction updated: a comfortable, friendly iPhone remote for living-room Windows and Mac computers, with Linux planned. Open-source project with a paid App Store convenience offering for nontechnical users. The first five concepts predate this scope update; none contains an OS logo.
